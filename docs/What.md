# Han_Ovarian 项目说明（What）

## 1. 这个项目是做什么的

这是一个面向 IVF（试管婴儿）场景的卵巢反应 AI 辅助决策系统，核心目标是：

- 预测患者发生低卵巢反应（POR）和高卵巢反应（HOR/OHSS）的风险；
- 在风险基础上给出促排方案建议（方案方向、FSH 起始剂量、是否补充 LH 等）；
- 提供可直接给临床使用的交互界面（Streamlit）和批量上传能力（Excel/CSV）。

项目是 Python 工程化版本，包含训练、推理、临床规则和前端展示全链路。

## 3. 用了什么方法（技术与建模路线）

## 3.1 建模方法

- 采用 **4 个 XGBoost 二分类子模型**并行：
  - `PORDM`：POR 诊断模型
  - `HORDM`：HOR 诊断模型
  - `PORSM`：POR 策略模型（含干预特征）
  - `HORSM`：HOR 策略模型（含干预特征）
- 训练支持两种模式：
  - 快速模式：固定参数训练
  - 调参模式：基于 Optuna TPE 的超参数搜索（AUC 为目标）

## 3.2 数据预处理方法

- 分层切分（按目标标签）保持训练/测试分布稳定；
- 缺失值处理：`IterativeImputer + RandomForestRegressor`（MICE 思路）；
- 分类变量处理：one-hot 编码；
- 特征工程：区分诊断模型与策略模型（策略模型额外含干预特征）。

## 3.3 推理与临床决策方法

- 推理层将单患者字典转换为 DataFrame，并对齐训练时特征列；
- 临床层将模型概率映射为低/中/高风险（阈值规则）；
- 规则引擎生成建议：
  - 促排方案方向
  - FSH 起始剂量区间（可按体重上/下调）
  - FSH 类型建议
  - LH 支持建议
  - 预估获卵数区间
- 输出临床可读总结文本，前端直接渲染。

## 3.4 前端与交互方法

- Streamlit 双栏布局：左侧“卵巢储备评估”，右侧“促排方案建议”；
- 支持模板下载、Excel/CSV 批量上传、列名别名识别、患者切换；
- 当无本地模型时可自动回退到“演示模型”（合成数据即时训练）；
- 引入外部参考接口（OvaRePred），并在不可用时使用本地估算回退策略。

## 4. 已实现的功能清单

## 4.1 训练与评估

- CLI 训练入口（真实数据/合成数据/演示模式）；
- 四模型批量训练和评估（AUC、Brier）；
- 模型持久化保存与加载（新格式 `json+meta`，兼容 `pkl`）。

## 4.2 推理与决策

- 单患者四概率输出：`prob_POR_dm` / `prob_HOR_dm` / `prob_POR_sm` / `prob_HOR_sm`；
- 风险分层（低/中/高）；
- 临床推荐（方案、剂量、药物类型、LH 支持、获卵数）；
- 干预方案比较能力（`compare_interventions`）。

## 4.3 前端能力

- 双模块页面（储备评估 + 促排方案）；
- 输入校验与错误提示；
- 批量上传解析（中英文/别名列头）；
- 结果可视化展示（环形进度、风险条、指标卡）；
- 模型来源自动识别（预训练模型 / 演示模型）。

## 4.4 工程质量

- 单元测试：预处理、模型、推理、临床规则、上传解析；
- 集成测试：从数据到建议的端到端流程；
- 包结构模块化，含兼容层（保持旧导入路径可用）。

## 5. 文件夹分配（按职责）

## 5.1 核心后端

- `ovarian_prediction/`
  - `preprocessing/`：数据加载、清洗、切分、插补、编码、合成数据
  - `models/`：XGBoost 子模型与四模型系统管理
  - `inference/`：单患者输入适配与四模型推理
  - `clinical/`：风险阈值、规则建议、报告生成、决策系统
  - `training/`：训练编排器和 CLI
  - `config/`：全局常量和路径定义
  - 根下兼容层文件：保留旧模块导入方式

## 5.2 前端

- `frontend/streamlit_app/`
  - `main.py`：主页面与交互流程
  - `components/`：布局、指标卡、结果面板
  - `services/`：模型加载、上传解析、参考接口、报告适配
  - `state/`：Session State 初始化
  - `utils/`：格式化与媒体资源工具
  - `assets/`：图片、模板、样式资源

## 5.3 产物与文档

- `artifacts/`
  - `models/xgboost/`：当前模型主产物目录
  - `preprocessors/`：预处理器产物
  - `demo/`：演示与验证产物
- `models/`：旧版模型兼容目录
- `docs/`：项目文档与研究归档
- `tests/`：单元测试与集成测试
- `scripts/`：预留脚本目录
